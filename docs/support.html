Contact

Best place for bugs and feature requests: GitHub Issues.

Other questions: ankush.one or github.com/ankushKun.

There is no Mixtunes account, support chatbot, or phone line. Replies are best-effort from a single maintainer.

Where it works

  • YouTube Music today — music.youtube.com
  • Browsers: Chrome 121+, Firefox 142+, and Chromium-based desktops (Edge, Brave, Arc, Vivaldi, Opera, Zen)
  • Not yet: Safari, phones/tablets, Spotify, Apple Music, SoundCloud (those hosts are under development)

Install

Prefer the Chrome Web Store listing. Firefox is still in review — until then, use a GitHub release zip and load it unpacked (Chrome-family) or as a temporary add-on (Firefox). Step-by-step: Install on the homepage.

Releases: github.com/ankushKun/mixtunes/releases.

Turn the theme on or off

  • Toolbar popup — toggle Show Mixtunes overlay. Turning it off reloads stock YouTube Music.
  • Preferences — open settings in the shell and choose Original YouTube Music.
  • One-shot escape — add ?newytm=true to a YouTube Music URL to skip the overlay for that load.

Common fixes

  • Nothing appears — confirm you are on music.youtube.com (not youtube.com), the extension is enabled, and the overlay toggle is on. Try a hard refresh.
  • Empty library — sign in to YouTube Music in that tab. Signed-out sessions still show the shell, but lists stay empty.
  • Playback oddities — Mixtunes drives the host player; if audio fails, check YouTube Music itself (Premium limits, ads, network). Reloading the tab usually re-hooks the player.
  • Old Firefox — Mixtunes needs Firefox 142 or newer.

Report a bug

Open an issue on GitHub and include:

  • Browser and version (Chrome / Firefox / …)
  • Mixtunes version (from the store or the release zip name)
  • What you expected vs what happened
  • A short screen recording or screenshot if the UI is wrong
