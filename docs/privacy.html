What yTunes is

yTunes is a local overlay for YouTube Music. It does not run its own servers and does not send your music, account, or browsing data to the developer.

Data stored on your device

The extension uses the browser’s storage API (chrome.storage.local) for preferences such as overlay on/off, theme (Metal / Graphite / Auto), and similar UI settings. That data stays in your browser profile. Uninstalling yTunes deletes it.

Data read on the player site

While you are on music.youtube.com, yTunes reads the page so it can show your library, playlists, and now-playing state, and so it can control playback. It uses cookies and session tokens that YouTube Music already placed on that site to call YouTube’s own APIs from the tab. Those requests go to YouTube, not to yTunes.

What we do not do

  • No analytics, advertising, or crash-reporting SDKs.
  • No accounts, mailing lists, or developer-operated backend.
  • No sale or transfer of user data to third parties.
  • No collection of payment, health, or location data.

Permissions

storage: save overlay and appearance preferences on this device. Host access to music.youtube.com: inject the overlay and talk to the YouTube Music player in that tab only. Future player support (Spotify, Apple Music, SoundCloud) would add equivalent host-permissions for those sites only, and this policy will be updated before that ships.

Changes

If data handling changes, this page will be updated and the Chrome Web Store / Firefox Add-ons listings will be revised to match.
