What Mixtunes is

Mixtunes is a classic iTunes theme for Spotify, YouTube Music, SoundCloud and Apple Music. Today it runs on YouTube Music; the other hosts are under development. The browser extension does not run its own servers and does not send your music, account, or player browsing data to the developer.

Data stored on your device

The extension uses the browser’s storage API (chrome.storage.local) for preferences such as theme on/off, appearance (Metal / Graphite / Auto), and similar UI settings. That data stays in your browser profile. Uninstalling Mixtunes deletes it.

Data read on the player site

While you are on music.youtube.com, Mixtunes reads the page so it can show your library, playlists, and now-playing state, and so it can control playback. It uses cookies and session tokens that YouTube Music already placed on that site to call YouTube’s own APIs from the tab. Those requests go to YouTube, not to Mixtunes.

This marketing website

The pages at ankush.one/mixtunes (this site) are separate from the extension. They use PostHog (EU Cloud) for product analytics so we can see which pages and install buttons people use.

  • Events are sent through a first-party reverse proxy at p1.ankush.one, then processed by PostHog in the EU.
  • Typical data includes page views, button clicks (including install CTAs), browser type, approximate region derived from IP, and a random anonymous visitor id. We do not call identify() with your name or email on this site.
  • PostHog may store a small amount of data in cookies or local storage in your browser for that anonymous id, unless you opt out or your browser sends Do Not Track.
  • Session replay is turned off in the site’s PostHog config.
  • PostHog’s own terms and privacy policy apply to their processing: posthog.com/privacy.

The browser extension does not include PostHog or any other analytics SDK.

If Mixtunes is installed, this site can read the extension’s version in your browser so it can show it next to the latest GitHub release. That check stays in the tab. It is not sent to PostHog or to the developer.

Website analytics are on in this browser.

What we do not do

  • No analytics, advertising, or crash-reporting SDKs inside the extension.
  • No Mixtunes accounts, mailing lists, or developer-operated player backend.
  • No sale of your music library or account data.
  • No collection of payment, health, or precise location data.

Permissions

  • storage: save theme and appearance preferences on this device.
  • Host access to music.youtube.com: inject the theme and talk to the YouTube Music player in that tab only. Future player support (Spotify, Apple Music, SoundCloud) would add equivalent host-permissions for those sites only, and this policy will be updated before that ships.
  • Host access to ankush.one (and localhost / 127.0.0.1 when previewing the site): tell the landing page which Mixtunes version is installed, including Chrome Web Store, GitHub zip, and unpacked loads. Chrome may also let the page ask the extension for that version directly. Either way only the version string is exchanged, in this tab.

Changes

If data handling changes, this page will be updated and the Chrome Web Store / Firefox Add-ons listings will be revised to match.
